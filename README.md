# Viode downloads

Installers for [Viode](https://eduardmoldovan.com/viode) attach to the
releases here. Every direct download is complete in itself; details on
installing are in [the manual](https://eduardmoldovan.com/viode/manual).

**Arch Linux:** until `viode-bin` reaches the AUR, install from this
repository:

```bash
git clone https://github.com/edimoldovan/viode-releases
cd viode-releases/viode-bin
makepkg -si
```
